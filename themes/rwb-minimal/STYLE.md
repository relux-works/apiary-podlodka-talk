# Гайд: стиль «RWB minimal» для Slidev

Гибрид корпоративного шаблона RWB и авторской системы докладов: тёмный типографический стиль developer-session с брендовыми акцентами, векторными пиксельными мотивами и скромным логотипом. Для сложных технических тем, где содержание важнее оформления.

Проверено на Slidev 52.19.1: `npm run theme:rwb-minimal` открывает витрину, `npm run verify` проходит для дека на этой теме.

Комплект: `themes/rwb-minimal/` — локальная тема Slidev (`slidev-theme-rwb-minimal`), `themes/rwb-minimal/example.md` — витрина всех раскладок и компонентов на слайдах доклада iOS Crew #18, где тема родилась. Подключение к деку, логотип и смена темы — в [`../README.md`](../README.md).

---

## 1. Канон в десяти правилах

1. **Одна композиция на слайд.** Без построений и суб-слайдов: слайд показывает законченную мысль своей части. Анкер один — таблица, код, диаграмма или утверждение.
2. **Тёмный фон `#0B0D12`, текст `#EDEDF0`.** Никаких заливок на всю страницу, включая фиолетовую из шаблона.
3. **Три брендовых акцента с закреплённой семантикой:** сирень `#BF97F1` — модель и веса, оранжевый `#FE5F00` — цена и внимание, лайм `#94E330` — проверка и успех. Не больше двух акцентов на слайд. Числа и заголовки белые.
4. **Глубокий фиолетовый `#7F30E3` — только плашка** слева на открывашке части. Как текст на чёрном он не читается.
5. **Логотип RWB — на титуле и финале,** высота 28 px (≈ 5% высоты слайда), правый угол. На рабочих слайдах логотипа нет: компания — партнёр площадки, доклад — не рекламный носитель.
6. **Пиксельный мотив — вектор,** один на слайд, только на титуле, открывашках и финале. Никогда за текстом, никогда как маркер списка.
7. **Без карточек, бенто-сеток, 3D-иконок, мокапов, теней и градиентов.** Контурные блоки допустимы только как узлы диаграмм и шаги процесса.
8. **Заголовки — утверждения или вопросы** в sentence case. Без лозунгов, метафор в заголовках и конструкций «не X, а Y».
9. **Минимальный кегль — 13 px** (вторичные подписи и источники). Текст 17–21, заголовок 30, код 16, таблицы 15.
10. **Источник или метка измерения — внизу слайда** одной строкой: ЗАМЕР · ФАКТ · БЕНЧ · КОМЬЮНИТИ · ОЦЕНКА, плюс ссылка. Плейсхолдеры и [VERIFY] — янтарным моноширинным `<Ph>`, до финала исчезают.

## 2. Токены

CSS-переменные (`themes/rwb-minimal/styles/base.css`) и цвета UnoCSS (`themes/rwb-minimal/uno.config.ts`):

| Роль | Переменная | Значение | Uno |
|---|---|---|---|
| фон | `--rwb-bg` | `#0B0D12` | `bg-bg` |
| поле кода | `--rwb-code` | `#121924` | `bg-code` |
| узел диаграммы | `--rwb-node` | `#181D28` | `bg-node` |
| подсветка строки кода | `--rwb-hl` | `#20304A` | — |
| текст | `--rwb-txt` | `#EDEDF0` | `text-txt` |
| вторичный | `--rwb-sec` | `#A3A8B1` | `text-sec` |
| неактивный | `--rwb-dim` | `#4D525C` | `text-dim` |
| линейка | `--rwb-rule` | `#2A2F3A` | `border-rule` |
| сирень · модель, веса | `--rwb-lilac` | `#BF97F1` | `text-lilac` |
| оранжевый · цена | `--rwb-orange` | `#FE5F00` | `text-orange` |
| лайм · проверка, успех | `--rwb-lime` | `#94E330` | `text-lime` |
| глубокий фиолетовый · плашка | `--rwb-deep` | `#7F30E3` | `bg-deep` |
| ошибка (вне бренда) | `--rwb-err` | `#E07A74` | `text-err` |
| плейсхолдер (вне бренда) | `--rwb-ph` | `#D0A461` | `text-ph` |

Шрифты: **Inter** (текст), **JetBrains Mono** (код, теги, числа). Тема подключает их через `fonts` в `package.json` → Slidev тянет из Google Fonts; для офлайн-показа положите woff2 в `public/fonts` и добавьте `@font-face` в `styles/base.css`.

Кегли для канваса 980×552 px: заголовок 30 · открывашка 44 · утверждение 36 · текст 19 (колонки 17) · таблицы 15, шапка 13.5 · код 16 · источники и теги 13 · большое число 44 (mono).

Отступы: `px-16 py-10` — safe area ≈ 6.5% по ширине.

## 3. Раскладки

Раскладка задаётся во frontmatter слайда: `layout: …`. Остальные ключи frontmatter — свойства раскладки.

| layout | Свойства | Слоты | Для чего |
|---|---|---|---|
| `cover` | `event`, `who`, `role`, `contacts`, `logo` (true), `motif` (arrow) | default | титул: логотип справа сверху, мотив справа снизу |
| `section` | `num`, `sub`, `motif` (check) | default = заголовок | открывашка части: фиолетовая плашка слева, мотив |
| `default` | `tag`, `source` | default | рабочий слайд: тег части сверху, источник внизу |
| `two-cols` | `tag`, `source` | `::title::`, default (левая), `::right::`, `::bottom::` | сравнение двух колонок по одной оси |
| `code-side` | `tag`, `source` | `::title::`, default (код), `::side::` | код 2/3 ширины + пояснение справа |
| `demo` | `tag`, `question`, `expect`, `where`, `fallback`, `source` | `::title::`, default (конфиг) | бампер перед записью |
| `statement` | `tag`, `after` | default | одно утверждение крупно |
| `end` | `who`, `contacts`, `qrs` (массив подписей), `logo`, `motif` | default | финал: три места под QR, логотип справа снизу |

Именованные слоты в Markdown — через маркеры `::title::`, `::right::`, `::side::`, `::bottom::`; содержимое до первого маркера или после `::default::` идёт в основной слот. Все примеры — в `themes/rwb-minimal/example.md`.

## 4. Компоненты

Регистрируются автоматически из `themes/rwb-minimal/components/`.

| Компонент | Использование | Назначение |
|---|---|---|
| `<Tag text="…" />` | сверху слайда (в раскладках уже есть) | тег части: mono, uppercase, сирень |
| `<SourceNote text="…" />` | внизу слайда (в раскладках через `source:`) | источник, метка измерения |
| `<Ph>⟨…⟩</Ph>` | внутри текста | плейсхолдер / [VERIFY], янтарный mono |
| `<PixelMotif pattern="arrow|check|plus" :cell="22" />` | абсолютное позиционирование классами Uno | пиксельный мотив, вектор |
| `<RwbLogo :height="28" />` | титул и финал | логотип из `themes/rwb-minimal/assets` |
| `<Boxes :items="['a','b','c']" :arrows="true" color="lilac" />` | шаги процесса, элементы контракта | ряд контурных блоков со стрелками |
| `<Stack :layers="[['Среда','цикл и инструменты','lilac'], ['Движок','исполняет модель']]" />` | слои стека | вертикальные контурные слои |
| `<BigNum value="$4.57" caption="…" />` | числа-якоря | большое моноширинное число с подписью |

Таблицы — обычный Markdown; стиль (тонкие линейки, сиреневая шапка) применяется автоматически. Код — обычные блоки ` ```bash {7,8} ` с подсветкой строк; цвета синтаксиса из брендового варианта: ключевые слова и флаги — сирень, строки и числа — оранжевый (`themes/rwb-minimal/setup/shiki.ts` + `rwb-dark.json`).

Диаграммы посложнее (граф задач, цикл проверки) — inline SVG прямо в слайде: узлы `rect` с `fill="var(--rwb-node)"` и `stroke="var(--rwb-lilac)"`, рёбра `line` цветом `--rwb-sec`, подписи `text` 13 px mono. Координаты фиксируем руками; никаких автолейаутов. Размер и шрифт подписей задаёт тема (`.slidev-layout svg text`); атрибуты `font-size`/`font-family` на `<text>` не ставить — UnoCSS attributify читает `font-size="13"` как утилиту и выдаёт 3.25rem.

## 5. Что менять и чего не трогать при работе со слайдами

- Порядок и содержание — из авторского текста и плана доклада. Раскладки подбирать по `themes/rwb-minimal/example.md`: где две колонки — `two-cols`, где шаги — `<Boxes>`, где слои — `<Stack>`, где число — `<BigNum>`.
- Заметки спикера — в HTML-комментарии в конце слайда, это абзацы текста доклада. Не сокращать.
- Открывашки частей (`section`) — по решению автора, одной строкой frontmatter.
- Финал: тёмный (как в теме). Фиолетовая версия на всю страницу — только по прямой просьбе компании, отдельным слайдом после содержания.
- Логотип: `cover` и `end` показывают его сами; на других раскладках `<RwbLogo>` не используем.

## 6. Запуск и экспорт

```bash
npm install
npm run theme:rwb-minimal                # витрина темы, http://localhost:3030
npm run dev                      # дек из slides/slides.md
npm run verify                   # lint → офлайн-сборка → аудит всех слайдов
npm run export                   # PDF в .temp/export/
```

Экспорт в PDF идёт с реальными шрифтами; в PowerPoint-экспорт каждый слайд попадает картинкой — редактируемым он не будет, это ограничение Slidev.

## 7. Чеклист перед показом

- на каждом слайде один анкер и не больше двух брендовых акцентов;
- логотип только на титуле и финале; мотив только на титуле, открывашках, финале;
- ни одного текста меньше 13 px; код ≤ 14 строк; таблицы ≤ 6 строк;
- заголовки — утверждения или вопросы, без «не X, а Y»;
- все `<Ph>` заменены реальными значениями или слайд помечен как черновой;
- источники внизу там, где на слайде есть число или чужой факт;
- экспорт в PDF открыт и пролистан: переносы заголовков, обрезанные таблицы, шрифты.
