# Как открыть презентацию

Внутри архива — статическая сборка Slidev: `index.html` и папка `assets/`.

**Двойным кликом по `index.html` она не откроется.** Браузер грузит слайды как
ES-модули, а для `file://` это запрещено CORS-политикой — страница останется
пустой. Это ограничение браузера, а не сборки. Нужен любой локальный HTTP-сервер.

## Запуск

Распакуйте архив и выполните в получившейся папке одну из команд:

```bash
python3 -m http.server 8080        # есть на любом маке из коробки
npx serve .                        # если есть Node.js
php -S localhost:8080              # если есть PHP
```

Затем откройте <http://localhost:8080>.

## Управление

| Действие | Клавиши |
| --- | --- |
| Следующий слайд | `→`, `Space` |
| Предыдущий слайд | `←` |
| Обзор всех слайдов | `o` |
| Режим докладчика с заметками | `p` |
| Полноэкранный режим | `f` |
| Рисование поверх слайда | `d` |

Прямая ссылка на слайд — через хэш: `http://localhost:8080/#/9`.

## Без интернета

Шрифты Inter и JetBrains Mono подтягиваются из Google Fonts. Без сети слайды
откроются, но подставятся системные шрифты — метрики поедут. Для показа офлайн
положите woff2 в `slides/public/fonts` и добавьте `@font-face` в `themes/<тема>/styles/base.css`
перед сборкой.

Если сеть недоступна, а вид должен быть точным — показывайте PDF из этого же
релиза.
