# Профиль 1: ограниченная память, один контекст

::default::
```bash {7,8}
./build/bin/llama-server \
  -hf unsloth/Qwen3.8-27B-GGUF:UD-Q4_K_M \
  --no-mmproj \
  --alias qwen-local \
  --host 127.0.0.1 --port 8080 \
  -ngl 99 --fit off \
  -c 8192 -np 1 --no-kv-unified \
  --cache-ram 0 -b 256 -ub 128 \
  --jinja \
  --temp 1.0 --top-p 0.95 --top-k 20 --min-p 0.0
```

::side::
## Что важно на 24 GB

- 8K — общий бюджет входа и ответа одной последовательности
- RAM-кеш snapshots отключён; KV слота работает
- `--fit off` делает лимиты явными
- Проверить memory pressure с Xcode и симулятором
